# Renderer synthetic fixtures

These files are **synthetic renderer tests**, not AW product assets, facts, approved designs, or exports.

`fixture-sans-regular.ttf` is an OFL 1.1 derivative of Noto Sans SC from the [Google Fonts repository](https://github.com/google/fonts/tree/a85815a42757630ce188fdad368c2dfc444d4773/ofl/notosanssc). The included `OFL.txt` preserves the upstream copyright and license. The derivative is renamed **Tujiang Renderer Fixture Sans**, instantiated at weight 400 and subset to ASCII plus the test corpus. It is deliberately not a general Chinese production font; unsupported characters produce `FONT_GLYPH_MISSING` instead of a system font fallback.

- Upstream commit: `a85815a42757630ce188fdad368c2dfc444d4773`
- Upstream file: `ofl/notosanssc/NotoSansSC[wght].ttf`
- Upstream SHA-256: `a3041811a78c361b1de50f953c805e0244951c21c5bd412f7232ef0d899af0da`
- Derived font SHA-256: `84366fc4ae40fc5cad8e51ed43a567ae8c7ebef9d30096ceec1b024d2ea08939`
- Generator: `prepare-fixtures.py`, Python 3.10.9, fontTools 4.53.1. Pass the downloaded fixed upstream TTF path as the only argument. The font timestamps and naming are fixed. Network is used only when preparing this development fixture, never during compilation or review rendering.

`synthetic-bottle.png` is an original procedural 600 × 400 RGB illustration generated by the same script, dedicated to the public domain under [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Its SHA-256 is `4a9571a85aef2652e5feb20096731a29192f8a3e03cc1a91ef06160e182246e4`. It makes no product claim. This fixture generator uses only Python stdlib for the PNG and is not a runtime dependency.

`synthetic.ts` defines one representative Section with two Frames. It includes Chinese, English, a fixed image, body copy, a ParameterTable and clear review-sample labels. Ref hashes are computed over the synthetic ref contents; they do not attest real product facts.
