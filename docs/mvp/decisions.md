# MVP 实现决定

所有决定服务于已批准文档语义，不能覆盖其业务规则。

## D001：兼容和正式对象

`stage-a.1` 与现有诊断语义保留。正式数据使用可选 `Project.production`、独立 `production.1` 契约。初始化通过显式写命令进行，读取不静默迁移。旧 `sections` 的 `diagnostic_draft` 不自动成为制作章节，也不产生批准记录。旧项目、历史快照和幂等回执保留原值。

正式业务对象独立保存 ID、修订、批准快照和依赖；当前数组位置不得成为章节 ID。批准版本固定其输入，后续变动创建新版本或候选。

## D002：M1 接口

- `GET /api/projects` 返回 `{ projects: [{ id, name, version, revision, contractVersion, updatedAt }] }`，按更新时间降序、ID 稳定排序；使用现有 Bearer 身份。
- `GET /api/projects/:id` 保持原响应结构，允许新增可选 `production`。
- `POST /api/projects/:id/production/initialize` 使用现有预期版本与幂等参数，初始化空正式域；重复初始化不新建业务版本。
- `GET /api/contracts` 保留原契约并公布新增命令及正式契约版本。

## D003：会话、事件与草稿

SSE 使用带 Authorization 的 fetch 流。事件 ID 是审计游标，不是项目 revision；收到事件后读取项目快照，不把事件正文当作 Project。重连有退避，只重试读取，不能重放业务 POST。旧快照不能覆盖新快照。

凭据仅驻留内存；草稿按项目与对象隔离，恢复时校验上游依赖并要求复核。未决写入禁止切项目；已确定失败、冲突和身份过期有独立恢复路径。保留原操作编号显式重试。

## D004：真实结果与验收

确定性测试固定浏览器、字体、素材和 Renderer 版本。合成输入仅验证工程协议，真实语义需人工复核。原诊断 QA 与正式 QA／文件检查分离。未通过正式 QA、未批准、stale 或缺少文件时禁止交付。

## D005：Setup 功能与分布重验

2026-09-07，用户重申已确认的 Setup 功能与分布参考。保留岳凯六阶段视觉系统，左侧仅提供五类配置的定位锚点；中间五区按 01–05 单列连续排列；右侧汇总服务端启动检查、资料用途说明、阻断问题与建议。不能用单一完成百分比代替具体结果。

主操作文案固定为“创建项目并开始事实提取”。上传阶段可建立内部项目草稿承载原件，最终操作负责原子完成上下文、目标规则与初次提取输入绑定，员工无需依次操作内部初始化、身份确认、保存、启用等多个技术步骤。前端只呈现服务端返回的实际排队／等待／失败状态；没有可用提取输入或未配置 Worker 时，不虚报提取已运行。

Setup 展示系统预分类，员工无需在此逐文件确认用途。低置信、混合用途与高风险资料进入产品事实页的待处理中心。用途确认不会自动批准事实。平台、站点、语言、货币、单位与 RulePack 使用已支持的关联组合；CanvasProfile 在本阶段创建，全局宽度在章节制作中只读。

2C 原配置与恢复检查仍作为限定证据保存，但整页验收重新开放。2A3 负责服务端启动流程，2C2 负责连续表单与范围化目标编辑，2C3 接通最终主操作和右栏结果。整页结项须在真实后端验证主操作、锚点滚动、支持组合、阻断／建议及恢复；历史截图只能作为当时界面的证据，不能替代本次验收。

## D006：产品事实页功能分布与正式放行

2026-09-07，用户重申图 18-2 作为产品事实页的功能与分布参考。左栏承载资料与证据、增量上传、提取记录；中区提供统一待处理队列，并展开来源对照和缺口处理；右栏绑定当前事实，展示原始证据、Agent 解释、影响范围与结构化确认动作。用途审核与事实审核共用队列，但明确标识任务类型，只有上游用途和有效证据满足要求时才能推进对应事实动作。

Agent 可以解释冲突、查找其他来源、提出修改建议，不能替用户确认事实。确认、修改和拒绝都保留证据、操作者及变更记录；修改已锁事实通过新候选和显式审核，不覆盖历史。参考图中的 PDF/XLSX、示例数值和百分比不构成已实现能力或实际业务数据。

底部正式放行动作使用服务端 Facts 准备度与冻结接口：核心事实、冲突、必要缺口及 blocked 问题处理完毕才可用。未放行前允许生成仅引用已确认事实的无文案初步故事顺序，保持其诊断语义，不自动升级正式章节。2D2 的用途、候选和来源重确认属于限定子包；完整 Facts 页须在 3A/3C 接通多来源、缺口、解释和正式放行后整页验收。
