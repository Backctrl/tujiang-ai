# M2 2C2 连续设置表单与范围规则编辑

本包在原岳凯工作台的五个设置区消费 `backend/SCOPED-RULES.md` 冻结契约。它替换 2A2 为旧客户端保留的临时只读限制，支持完整范围规则草稿、历史复制、保存与启用。所有规则来自服务端目录；本包没有配置真实平台规则，也没有发起模型请求。

## 界面与规则边界

左侧五个锚点只滚动定位。中间始终渲染产品基础信息、产品资料、平台与站点、本地化、页面尺寸五个纵向区段。连接、项目列表、新建草稿与旧身份纠正收在独立项目入口中。布局仅在 `backend-integration.css` 的 `.connected-workbench .setup-workbench` 下覆盖，原全局 CSS 和其它五阶段不改。

| 配置 | 实际行为 |
|---|---|
| 平台 / 站点 / 内容类型 | 只从当前模式的服务端目录生成组合；也能手动保留未配置目标草稿 |
| 选择规则 | 带入该版本的目标、语言、货币、单位；范围模型同时明确 `local_production_policy` |
| 本地化主配置 | 只列当前平台 / 站点 / 内容类型在目录中的完整组合；一次选择同步国家、语言、货币、单位与精确规则引用，四个显示值只读 |
| 未配置目标 / 本地化 | 自由输入和原历史值保留在明确的仅草稿区，不加入主选择支持的选项；目录刷新不会静默换版 |
| 修改平台 / 站点 / 内容类型 | 清除原精确规则引用，依赖选择重新填写；不会沿用其它目标规则 |
| 本地画布 | `canvasWidthPx` 按 min / max / exact 检查，格式按 `canvasFormats` 检查 |
| 平台上传规则 | 显示 content / module / image_slot / text_field 的准确范围与来源，图片槽 minimum 不进入画布精确宽度建议 |
| 格式与交付 | `exhaustive=false` 明确显示已知子集和其它格式未核验；本地 HTML / PDF / WebP 等交付格式单独说明 |
| 启用前检查 | 精确目标字段、适用品类的 activationRequirements、unknown、目录缺失和同版本内容变化都会阻断；草稿仍可保存 |

产品名称、品类、阶段和介绍为必填；内部代号、商业目标选填。后端可选字段契约由 A 的 `ccdebf0483438c9b58198b5cea6487eb549a26e7` 提供，本包按该依赖联调。

## 草稿、历史与恢复

- 已启用 P 版本只读，需明确复制后编辑；复制保留全部 contentType、selectionBasis 和规则引用，不改变原 P 或规则哈希。
- 切换新旧规则类型先展示差异，当前字段按项目/模式保留本地备份；首次转换清除跨模型规则引用。恢复备份继续使用原依赖，外部变化需要明确复核。
- 旧 `productionContext` / `productionContext:reviewed` 草稿键保留。缺新增字段的旧表单先展示原输入并要求转换；新增字段只取自其记录的原 base，不从当前服务端版本静默补入。无法表示的未知字段保留原 JSON 并禁止保存。
- 当前目录暂缺时仍展示对应冻结规则；历史快照可以完整复制和保存草稿，不能充当可用目录绕过启用检查。
- GET / SSE 同批新快照、不同项目、较晚本地输入或新复制对话框不会被旧保存回执清空。复制比较期间暂停编辑和保存，旧确认回调不能替换新的比较。
- Catalog 一次 GET 原子发布两组规则，旧 `catalog()` 方法继续返回 legacy 数组；凭据变化与迟到读取不会恢复旧可写目录。
- 未决请求、认证失效与版本冲突仍由会话统一门控；没有新增自动 POST，也没有将配置写入伪装为事实提取。

## 验证与交接

`scoped-context-compatibility.test.ts` 使用实际 React Hook 检查两种模型、部分草稿、旧格式迁移、历史复制、模式备份、同批快照和旧回调。`scoped-setup-client.test.ts` 使用真实 loopback HTTP、实际 Hook 和组件检查完整目录、范围边界、保存/启用 P1/P2、401 原正文/编号重放、可选字段以及表单分布。继续运行既有 context/session/material/review/draft/frontend/chapter 客户端回归，前后端类型检查、前端 ESLint 与 Vite 构建。SSR 验证不替代浏览器布局或真实 IndexedDB 验收。

主任务使用隔离 PostgreSQL 与合成规则做 1440 / 1200 px 浏览器验收：确认 03、04 为纵向连续区段，锚点不隐藏其它段；检查 scoped 新建/复制/保存/启用、unknown/missing 阻断、旧规则继续编辑、目录缺失时历史可读和草稿恢复。可复用 2A2 的合成 fixture，但其旧文档中的“范围模型暂不可编辑”是已被本包替换的兼容阶段行为。

本包是 Setup 的中间交付。右侧目前明确标为配置草稿检查，不宣称启动就绪；底部还保留已有 Facts 导航。后续 2C3 按 `backend/STARTUP.md` 接服务端 blockers/suggestions、原件统计、真实启动主按钮“创建项目并开始事实提取”、明确等待状态及继续提取，最终再按用户整页参考验收。2D2 只完成资料用途与来源复核，新的 Facts 整页分布和正式放行门属于后续 3C1。
